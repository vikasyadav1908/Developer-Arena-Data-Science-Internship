## Project Overview

This project predicts house prices using machine learning techniques based on features such as area, bedrooms, bathrooms, age, location and property type.

## Models Used

* Linear Regression
* Decision Tree Regressor
* Random Forest Regressor

The models were evaluated using:

* Mean Absolute Error (MAE)
