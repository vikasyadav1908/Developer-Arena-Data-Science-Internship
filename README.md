# 🎓 Student Grade Calculator

## 📌 Project Description

The Student Grade Calculator is a Python-based program that takes a student's name and marks as input. It validates the marks, calculates the grade using conditional statements, and displays an encouraging message based on the student's performance.

## 🎯 Objective

The objective of this project is to practice basic Python programming concepts such as:

- If-else statements
- If-elif-else conditions
- Comparison operators
- For loops
- While loops
- Functions
- Input validation
- Basic error handling

## 📊 Grading System

| Marks | Grade |
|-------|-------|
| 90 - 100 | A |
| 80 - 89 | B |
| 70 - 79 | C |
| 60 - 69 | D |
| 0 - 59 | F |

## 🛠️ Technologies Used

- Python
- VS Code
- GitHub

## ⚙️ Features

- Accepts student name
- Accepts marks between 0 and 100
- Validates marks input
- Handles invalid and non-numeric inputs
- Uses if-elif-else statements
- Uses while loop for input validation
- Uses reusable functions
- Displays encouraging messages for each grade
